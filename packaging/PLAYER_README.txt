AstralCore v0.1.0-alpha

This download includes the game, its assets, and Java. No separate Java installation is needed.

APPLE SILICON MAC
Extract the entire ZIP. Open AstralCore.app; you can move it to Applications first.
This alpha is not Developer ID signed or notarized, so macOS may display a security warning.

WINDOWS x64
Extract the entire ZIP first, then open AstralCore.exe.
Keep the app and runtime folders beside AstralCore.exe. Do not launch from inside the ZIP.
This alpha is not code-signed, so Windows may display an unknown-publisher warning.

CONTROLS
WASD: move. Left mouse: attack/cast. E: interact. 1-5: skills.
C: equipment/inventory. Esc: options or close shop/dialogue. P: pause in single-player.
Enter: chat. Hover shop items and skills for details.

GETTING STARTED
Talk to the old man at the plaza, accept his quest, and enter the village well.
Defeat ten slimes and the Slime King, then report back for your class weapon.
Slime Essence can be offered at the well altar to challenge Hell Slime.
A party wipe resets a surviving boss; defeated players respawn at the plaza.
Quest/character progress is session-based in this alpha; there is no persistent save game yet.

CO-OP
Use the same game version on every computer. One player hosts; others enter the host's address.
Allow the game through the host's firewall for incoming TCP port 5001.
Connections over the internet may require the host's router to forward that port.

SETTINGS AND LOGS
Mac: ~/Library/Application Support/AstralCore/
Windows: %LOCALAPPDATA%\AstralCore\
Startup errors are recorded in logs/latest.log inside that folder.

This is an early alpha. Features, balance, and compatibility will continue to change.
