# v0.2.0-alpha - World Update

## What's New

### Procedural World Generation (Version 11)

The alpha now features **procedurally generated worlds** with version 11 generator:

- Open terrain zones: Flower plains, forest groves, pond shores, and rare golden meadows
- Modular cliff formations with 8% inland target / 10% maximum
- Physical elevation boundaries with connected cliff rendering
- Square/rectangular playable interior with irregular mask
- Deterministic seeds for reproducible worlds (use `/regenworld <seed>`)

Each world is generated once per character, preserving terrain state permanently.

### Three Playable Classes

Choose your combat style at creation:

| Class | Weapon | Progression System |
|-------|--------|-------------------|
| **Warrior** | Sword + Shield | Build Resolve through mitigation → counterattacks |
| **Mage** | Staff | Land spells to build runes → spend on empowered magic |
| **Hunter** | Dual daggers or bow | Land hits to build Focus → chain attacks into combos |

All classes have five abilities (Shift + 1–5).

### Character Customization

- **40 reference-inspired vector hairstyles** with front/side/back previews
- **20 muted hair colors** compatible with any style
- Equipment layers: clothing, boots, gloves, cloaks, and headwear (separate from weapons)

New characters begin unarmed with an empty bag; gather resources at your first station.

### Class Abilities

#### Warrior Abilities
Shield Bash, Bulwark, Retaliation, Shield Breaker, Rally

#### Mage Mechanics
- Place Ember and Frost spells with cursor positioning
- Spend runes on close-range Detonation or distant Cometfall
- Haste, ignition, and shielding abilities available
- Missed casts do not charge runes

#### Hunter Mechanics
- **Hunter (Dual Daggers)**: Quick strikes build Focus for combo finisher; Assassin path critiques on fourth cut
- **Hunter Ranger**: Tap left click for quick shot, hold until bow flashes for clean shot; charged arrows build Focus

### Additional Features

- Death memorials upon character death
- Five character save slots with auto-save every 30 seconds
- F5 manual save (also works in co-op sessions)
- Host/join co-op over TCP port 5001
- Adjustable display settings and pixel filter

## Download Notes

Every download includes Java, game assets, maps, and libraries. No separate Java installation needed.

**macOS:** Apple Silicon builds only. Not publisher-signed or notarized (security warning may appear).

**Windows:** x64 package with app and runtime folders included.

Port 5001 must be open for multiplayer connections.
